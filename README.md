## Descripción del Proyecto

Este proyecto contiene **10 sitios web de portfolio distintos** creados desde cero para un estudiante de Desarrollo de Aplicaciones Multiplataforma (DAM). Cada portfolio web presenta un diseño y estructura completamente diferentes, demostrando variedad y creatividad en el desarrollo frontend.

### Características del Proyecto

- **10 portfolios únicos** con diseños totalmente diferentes
- Tecnologías utilizadas: HTML, CSS, JavaScript, Tailwind CSS
- Frameworks modernos: React, Vue, Angular
- Librerías de animación: AOS, animaciones CSS personalizadas
- Diseño responsivo y accesible
- Iconos profesionales gratuitos (Font Awesome)

### Estructura de Cada Portfolio

Cada sitio web incluye las siguientes secciones:
- **Header** con menú responsive
- **Sobre mí**
- **Tecnologías** (lenguajes de programación y herramientas)
- **Proyectos** (2 proyectos: uno finalizado y uno en progreso)
- **Formación** (DAM y SMR)
- **Footer**

### Tecnologías y Herramientas

**Lenguajes de programación:**
- HTML5, CSS3, JavaScript
- Python, Java, C#

**Herramientas de desarrollo:**
- VSCode, Cursor
- IntelliJ, Eclipse
- Git, GitHub

### Portfolios Incluidos

1. **portfolio-1**: Diseño clásico y profesional
2. **portfolio-2**: Estilo moderno con gradientes
3. **portfolio-3**: Enfoque minimalista
4. **portfolio-4**: Diseño creativo con animaciones
5. **portfolio-5**: Tema cyberpunk futurista
6. **portfolio-6**: React con efectos glassmorphism
7. **portfolio-7**: Vue con tema oscuro y neon
8. **portfolio-8**: Angular con gradientes dinámicos
9. **portfolio-9**: Tema espacial con efectos cósmicos
10. **portfolio-10**: Diseño minimalista con timeline
